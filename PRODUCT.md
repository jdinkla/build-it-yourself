# Build It Yourself
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
delegated: Astro static output, GitHub Pages via GitHub Actions. The user explicitly delegates all decisions and asks for autonomous work through publication.
## Users
Editorial decision: curious non-specialists who want small personal digital tools without an account; capable readers who want to inspect and adapt them. No proven audience yet.
## Product Purpose
A web magazine where every issue leaves the reader with useful tools and a clearer understanding of how they work.
## Positioning
Original AI-written practical essays paired with inspectable browser tools, downloadable standalone HTML and portable data exports. Tools are the evidence; authorship is disclosed.
## Capabilities and Constraints
Static hosting; no backend, paid service, email collection, analytics, accounts or API keys. Six launch stories, three tools, issue archive, editorial policy, public management log, RSS. No automatic future publication is claimed. Noncritical personal data only. Storage on a shared GitHub Pages origin is not a security boundary.
## Evidence on Hand
Primary web documentation and working source. No interviews, hands-on field testing, audience metrics or testimonials. Synthetic examples must be labeled.
## Product Principles
- A reader should leave with something usable.
- Make data portable and limitations visible.
- Disclose AI authorship and review scope.
- Prefer a maintainable small publication to volume.
