# Asset provenance

No generated or stock images ship. Interface specimens are authored HTML with clearly illustrative values.

Fonts are self-hosted files from the Google Fonts repository, retrieved 8 November 2026, under the accompanying SIL Open Font License. Barlow and Barlow Condensed are by Jeremy Tribby; Source Serif 4 is Adobe's open-source serif family.

- https://github.com/google/fonts/tree/main/ofl/barlow
- https://github.com/google/fonts/tree/main/ofl/barlowcondensed
- https://github.com/google/fonts/tree/main/ofl/sourceserif4

The geometric favicon is original SVG source. Arrow marks are typographic navigation punctuation, not an icon system. System mono appears only in literal code/data.
